# Antigravityへコピペする修正依頼プロンプト

以下をそのままAntigravityへ貼り付ける。

```text
公開URL https://aitest496-admin.github.io/poket-plaque/ で実画面を確認した結果、以下の問題がありました。
このシステムは歯科のプラーク・歯周ポケット検査入力フロントPOCです。
既存UIの意図を保ち、無関係なリファクタリングや大きなデザイン変更はせず、下記の問題を優先順に修正してください。

## 最重要

保存済みデータの互換性をできるだけ壊さないでください。
既存の1点法、4点法、6点法、保存、読込、印刷プレビュー、PISA表示に副作用が出ないようにしてください。

## 1. 未保存データが日付切替で消える問題を修正してください

### 現象

1点法でポケット値を入力し、保存せずにカレンダーから別日付を選ぶと、確認なしで日付が切り替わり、入力中の値が消えます。

### 期待動作

isDirty が true の状態で日付を切り替えようとした場合、確認ダイアログを表示してください。

選択肢:

- 保存して移動
- 保存せず移動
- キャンセル

### 確認項目

- 未保存変更ありで「キャンセル」を選ぶと、日付も入力内容も変わらない
- 「保存して移動」を選ぶと、元の日付に保存してから移動先日付を読み込む
- 「保存せず移動」を選ぶと、保存せず移動先日付を読み込む
- 未保存変更なしの場合は今まで通りスムーズに日付切替できる

## 2. 検査実施者を保存・読込できるようにしてください

### 現象

実施者を「鈴木 和子」に変更して保存しても、ページ再読み込み後に保存日を開くと「山田 太郎」に戻ります。
実施者が検査記録に保存されていません。

### 期待動作

- ChartRecordに実施者情報を保存してください
- 読込時に実施者を復元してください
- 古い保存データに実施者情報がない場合は、デフォルト実施者で安全に表示してください

保存する情報は、少なくとも examinerId を含めてください。
必要なら examinerName, examinerColor も検討してください。

### 確認項目

- 実施者を変更して保存できる
- ページ再読み込み後、保存日を開くと同じ実施者が復元される
- 古い保存データでもエラーにならない
- 可能なら印刷プレビューにも実施者を表示する

## 3. 「データ削除」と「リセット」の意味を整理してください

### 現象

ヘッダーのツールチップは「データ削除」ですが、実際には現在表示中の入力値をリセットするだけです。
保存済みデータは削除されず、別日へ移動して戻ると保存済み値が復活します。

### 期待動作

以下のどちらか、または両方を明確に実装してください。

A. 編集中データのリセット
- ボタン名、ツールチップ、モーダル文言を「リセット」に統一する
- 保存済みデータは削除しないことが分かる文言にする

B. 保存済みデータの削除
- DentalDB.deleteChart(selectedDate) を使って保存済みデータを削除する
- 削除後、カレンダーの「データあり」マーカーを更新する
- 画面も空データに戻す

おすすめは、A「リセット」とB「保存済み削除」を別ボタンまたは別選択肢に分けることです。

### 確認項目

- リセットだけの場合、保存済みデータが残ることが文言から分かる
- 保存済み削除の場合、同じ日付を再読込しても古いデータが復活しない
- カレンダーのデータあり表示が正しく更新される

## 4. PISA画面で未入力データを健全と誤解しないようにしてください

### 現象

6点法で未入力のままPISA画面を開くと、PISA合計0.0、健全、BOP 0 / 192 のように表示されます。
未入力であることの注意がありません。

### 期待動作

- 6点法のPPD未入力サイト数を判定してください
- 未入力サイトがある場合、PISA画面上部に注意表示を出してください
- 全顎未入力の場合は「未入力のため評価できません」または同等の表現にしてください
- 一部未入力の場合は「未入力サイトあり。PISAは参考値です」と分かる表現にしてください

### 確認項目

- 全顎未入力では健全と誤解しない表示になる
- 一部未入力では注意が出る
- 全顎入力済みでは注意が消える
- 欠損歯は未入力判定から除外される

## 5. 10mm以上のポケット深さをタッチ入力しやすくしてください

### 現象

ポケット深さのクイック入力セルが1〜9mmまでしかありません。
10mm以上は手入力になり、重度部位の入力効率が落ちます。

### 期待動作

10mm以上をタッチで素早く入力できるUIを追加してください。

例:

- 10, 11, 12 のセルを追加
- または 10+ ボタンを追加し、タップ後に詳細値を入力できるようにする

### 確認項目

- 10mm以上をタッチ操作で入力できる
- 保存・読込後も値が残る
- 印刷プレビューで10mm以上が赤表示される
- PISA計算に反映される
- iPad縦向きでタップ対象が小さくなりすぎない

## 6. Tailwind CDNの本番警告を解消してください

### 現象

公開版のコンソールに以下の警告が出ています。

cdn.tailwindcss.com should not be used in production.

### 期待動作

- TailwindをViteのビルドに組み込んでください
- 公開版でTailwind CDN警告が出ないようにしてください
- オフライン運用や院内ネットワーク制限でもスタイルが崩れにくい構成にしてください

### 確認項目

- npm run build が成功する
- GitHub Pages公開版でコンソール警告が出ない
- 初期画面、入力画面、プレビュー、PISA画面の見た目が維持される
```
