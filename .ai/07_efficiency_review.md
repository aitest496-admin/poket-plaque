# 入力効率・操作性レビュー

## 目的

このシステムの価値は、歯周検査の入力時間を短縮し、入力ミスを減らすことです。単に動くかではなく、実際の検査テンポで使えるかを確認します。

## 観点1: 検査の流れに沿っているか

- [ ] 歯の移動順が検査者の読み上げ・入力の流れと合っている。
- [ ] 次に入力すべき場所が自然に分かる。
- [ ] クアドラント移動で迷わない。
- [ ] 右上、左上、右下、左下の移動が直感的。
- [ ] 入力後に視線を大きく移動しなくてよい。

## 観点2: タッチ操作しやすいか

- [ ] 主要ボタンが指で押せる大きさ。
- [ ] 隣の点を誤タップしにくい。
- [ ] 連続タップで反応が遅れない。
- [ ] ドラッグ入力やスワイプ入力時に意図しない値が入らない。
- [ ] iPadを片手で持った時に、よく使う操作が遠すぎない。

## 観点3: 入力ミスに気づけるか

- [ ] 入力済みの値が即座に見える。
- [ ] BOP、排膿、プラークの色や形が区別しやすい。
- [ ] 欠損歯・乳歯の状態が一目で分かる。
- [ ] 異常値や未入力が見つけやすい。
- [ ] 保存前に全体確認しやすい。

## 観点4: やり直しやすいか

- [ ] 誤入力をすぐ修正できる。
- [ ] 欠損歯にした後、解除して再入力できる。
- [ ] 測定法を間違えた時に復旧しやすい。
- [ ] 日付を間違えた時に保存前に気づける。
- [ ] 保存後に再読込して修正できる。

## 観点5: 時間短縮に効いているか

実測するときは、同じ患者モデルで以下を測る。

| シナリオ | 目標 | 実測 |
|---|---:|---:|
| 1点法で全顎入力 | 目標時間を記入 |  |
| 4点法で全顎入力 | 目標時間を記入 |  |
| 6点法で全顎入力 | 目標時間を記入 |  |
| BOPありケース入力 | 目標時間を記入 |  |
| プラーク入力 | 目標時間を記入 |  |
| 保存して印刷プレビュー確認 | 目標時間を記入 |  |

## antigravityへ改善依頼する時の書き方

```text
以下はバグではなく、入力効率改善の依頼です。

## 現状

[どの操作で時間がかかるか]

## 現場で困る理由

[検査中の流れにどう影響するか]

## 期待する改善

[例: 次の歯へ自動移動、タッチ範囲拡大、現在位置の強調、入力済み状態の視認性改善]

## 守ってほしいこと

- 既存の保存データ形式を壊さない
- 1点法、4点法、6点法の挙動を維持する
- iPad縦向き・横向きの両方で確認する
```
