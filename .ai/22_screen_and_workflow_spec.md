# 画面・操作フロー仕様

## 1. 基本方針

本システムは、歯周検査中にiPadを縦持ちして入力することを前提とする。入力者が患者の口腔内を見ながら、最小限の視線移動とタップ数で記録できることを優先する。

## 2. 主要画面

### 2.1 検査入力画面

目的:

- 歯周ポケット、BOP、排膿、動揺度、プラーク、根分岐部病変を入力する。

必須要素:

- 患者情報または患者識別情報
- 検査日
- 検査実施者
- 測定法切替
- 上下左右の歯列表示
- 現在入力対象の歯・部位が分かる表示
- 保存ボタン
- プレビュー表示ボタン

UX要件:

- iPad縦持ちで入力エリアを最大化する。
- 横幅をできるだけ使い、左右の余白を最小化する。
- ポケット入力は9mmまでを目盛り表示し、10mm以上は手入力にする。
- タップ対象は指で押しやすい大きさにする。
- 数値、BOP、排膿の入力状態が一目で分かる。

### 2.2 1点法入力

目的:

- 簡易的な歯周検査を少ないタップで記録する。

要件:

- 歯ごとに代表ポケット値を入力できる。
- プラーク入力と併用できる。
- BOP、排膿を入力する場合は、代表点として扱うか、別仕様にするかを本開発前に確定する。

### 2.3 4点法入力

目的:

- 4点法に必要な測定点のみを表示し、余計な入力欄を出さない。

要件:

- 6点法とデータ構造を共通化しつつ、表示点だけ4点に制御する。
- 4点法から6点法へ切り替えた場合、既存入力を保持する。

### 2.4 6点法入力

目的:

- 頬側3点、舌側3点のポケット、BOP、排膿を入力する。

要件:

- 頬側、舌側、遠心、中央、近心の位置関係が分かる。
- 根分岐部病変を入力できる。
- 入力済み値の視認性を高くする。
- 9mmまでの目盛りを表示し、10mm以上は手入力。

### 2.5 プラークチャート入力

目的:

- プラーク付着面を少ないタップで記録する。

要件:

- 遠心、頬側、近心、舌側、咬合面を入力できる。
- 面ごとのオン・オフが視覚的に分かる。
- 全面オン、全面オフなどの効率化操作を検討する。
- 1点法画面からもプラーク入力にすばやく移動できる。

### 2.6 担当者選択モーダル

目的:

- 検査実施者を選択・管理する。

通常モード:

- 「担当無し」を先頭に表示する。
- 非表示の担当者は一覧に出さない。
- 選択中の担当者が分かる。

追加モード:

- 「検査実施者を選択」の右側に＋マークを表示する。
- ＋を押すと名前入力欄と役割選択を表示する。
- 役割は歯科医師、衛生士。

編集モード:

- 「検査実施者を選択」の右側に編集ボタンを表示する。
- 担当者の順番を変更できる。
- 名前と役割を編集できる。
- 非表示にできる。
- 削除できる。
- 削除時は確認を表示する。
- 削除した担当者が過去検査に使われていた場合、過去検査は「担当無し」へ変更する。

### 2.7 カレンダー・履歴画面

目的:

- 過去の検査日を選択し、読み込み・比較する。

要件:

- 記録がある日付が分かる。
- 検査日を選択して読み込める。
- 比較対象として過去日を選べる。
- 誤って上書きしないよう、保存・読み込みの区別を明確にする。

### 2.8 プレビュー・印刷画面

目的:

- 入力内容を全顎で確認し、説明・印刷に使える形で表示する。
- プレビュー表を画像としてコピーし、他のアプリや資料へ貼り付けられるようにする。

要件:

- 検査日、担当者、測定法を表示する。
- ポケット、BOP、排膿、動揺度、プラーク、根分岐部病変を表示する。
- 根分岐部病変は表示・非表示を切り替えられる。
- 「根分岐部病変」表示切替の右側に「画像をコピー」ボタンを配置する。
- 「画像をコピー」ボタンをタップすると、プレビュー画面内の表を画像化してクリップボードにコピーする。
- プレビュー画面内に表が複数ある場合は、表示中のすべての表を1枚の画像としてまとめてコピーする。
- コピー対象は、操作ボタンや背景ではなく、検査表として利用するプレビュー表本体を基本とする。
- コピー処理中は連打を防ぐため、ボタンを処理中状態にする。
- コピー成功時は「画像をコピーしました」などの短い通知を表示する。
- コピーに失敗した場合は、ブラウザ制約などでコピーできないことを通知し、可能であれば画像保存や別タブ表示へ誘導する。
- iPad画面と印刷の両方で崩れない。

## 3. 主要操作フロー

### 3.1 新規検査

1. 患者を選択する。
2. 検査日を確認する。
3. 検査実施者を選択する。未選択時は「担当無し」。
4. 測定法を選択する。
5. 歯周検査値を入力する。
6. 必要に応じてプラーク、動揺度、根分岐部病変を入力する。
7. プレビューで確認する。
8. 保存する。

### 3.2 過去検査確認

1. 患者を選択する。
2. カレンダーまたは履歴から検査日を選択する。
3. 入力値、担当者、測定法、PISA/PESAを確認する。
4. 必要に応じて比較表示する。

### 3.3 プレビュー画像コピー

1. プレビュー画面を開く。
2. 必要に応じて根分岐部病変の表示・非表示を切り替える。
3. 「画像をコピー」ボタンをタップする。
4. 表が複数ある場合は、表示中の表すべてが1枚の画像としてクリップボードに入る。
5. コピー成功通知を確認する。
6. 必要なアプリや資料に貼り付ける。

### 3.4 担当者メンテナンス

1. 担当者選択モーダルを開く。
2. 追加、編集、並び替え、非表示、削除を行う。
3. 削除時は確認する。
4. 削除された担当者が過去検査に使われていた場合は「担当無し」へ変更される。

## 4. 実機確認観点

- iPad 第8世代の縦持ちで、入力欄が狭すぎないか。
- ポケット9mm目盛りが押しやすいか。
- 10mm以上の手入力に迷わないか。
- プラーク入力のタップ数が多すぎないか。
- 6点法と根分岐部病変の入力が混乱しないか。
- プレビューで根分岐部病変を表示しても画面が詰まりすぎないか。
- プレビューの「画像をコピー」ボタンが押しやすく、根分岐部病変の切替と混同しないか。
- コピーした画像が、貼り付け先で表として読める解像度になっているか。
- 複数表がある場合に、すべての表が欠けずにコピーされるか。
- 検査中に誤操作しても戻しやすいか。
