# 修正後の再検証チェック

antigravityによる修正後は、対象バグだけでなく周辺機能が壊れていないか確認する。

## 修正対象の確認

- [ ] 報告した再現手順で問題が再現しない。
- [ ] 期待結果通りに動く。
- [ ] 同じ操作を3回以上繰り返しても安定している。
- [ ] 別の日付、別クアドラント、別の歯でも破綻しない。

## 入力系の副作用確認

- [ ] 1点法の入力ができる。
- [ ] 4点法の入力ができる。
- [ ] 6点法の入力ができる。
- [ ] BOPのオン・オフができる。
- [ ] 排膿のオン・オフができる。
- [ ] プラーク5面の入力ができる。
- [ ] 動揺度0から3が入力できる。
- [ ] 欠損歯の切替ができる。
- [ ] 乳歯の切替ができる。

## 保存・読込の副作用確認

- [ ] 修正前に作成した保存データを読み込める。
- [ ] 修正後に新規保存できる。
- [ ] 保存後に同じ内容が復元される。
- [ ] 別日付のデータと混ざらない。
- [ ] 削除が対象日だけに効く。

## 表示・計算の副作用確認

- [ ] PISAプレビューが表示される。
- [ ] 欠損歯がPISAに含まれない。
- [ ] BOPなしのPISAが0になる。
- [ ] 印刷プレビューが表示される。
- [ ] 比較モードが表示される。
- [ ] iPad縦向き相当で表示崩れがない。
- [ ] iPad横向き相当で表示崩れがない。

## 完了判定

以下を満たせば、修正は一旦完了とする。

- 修正対象の問題が解消している。
- 保存・読込・印刷・PISAの主要導線に副作用がない。
- 新しい重大問題が発生していない。
- 残課題がある場合は `05_findings_log.md` に記録済み。
