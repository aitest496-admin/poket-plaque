# 検証チェックリスト

## 1. 初期表示

- [ ] アプリ起動時に画面が崩れない。
- [ ] 今日の日付が自然に選択される。
- [ ] 1点法、4点法、6点法の選択状態が分かる。
- [ ] 上下左右のクアドラント表示が分かりやすい。
- [ ] iPad縦向き相当の幅で主要ボタンが押せる。
- [ ] iPad横向き相当の幅で入力欄が窮屈にならない。

## 2. ポケット入力

- [ ] 1点法で想定した1点だけ入力できる。
- [ ] 4点法で想定した4点だけ入力できる。
- [ ] 6点法で6点すべて入力できる。
- [ ] 数値を連続入力しても遅延が目立たない。
- [ ] 入力値の変更が即時に画面へ反映される。
- [ ] 無効な値、空欄、連続タップで表示が壊れない。
- [ ] 上顎と下顎で入力位置が逆転していない。
- [ ] 右側と左側で歯の順番が臨床的に違和感ない。

## 3. BOP・排膿

- [ ] BOPをオン・オフできる。
- [ ] 排膿をオン・オフできる。
- [ ] 1点法、4点法、6点法で表示対象点が正しい。
- [ ] BOPと排膿の色や表示が混同されない。
- [ ] ドラッグ・スワイプ入力時に意図しない点が変わらない。
- [ ] 欠損歯ではBOP・排膿が入力できない、または入力値が計算から除外される。

## 4. プラーク入力

- [ ] 5面の入力状態が分かる。
- [ ] 各面を個別にオン・オフできる。
- [ ] 全面オン・オフ操作が期待通り動く。
- [ ] 欠損歯でプラーク入力が誤って集計されない。
- [ ] プラーク面の向きが上顎・下顎・左右で違和感ない。

## 5. 動揺度

- [ ] 0から3まで入力できる。
- [ ] 3を超えない。
- [ ] 0未満にならない。
- [ ] 欠損歯では動揺度が扱われない、または表示上明確に無効化される。

## 6. 歯の状態

- [ ] 欠損歯に切り替えられる。
- [ ] 欠損歯を解除できる。
- [ ] 乳歯に切り替えられる。
- [ ] 欠損歯と乳歯の表示が混同されない。
- [ ] 一括設定の「全欠損」「全乳歯」「リセット」が期待通り動く。
- [ ] 一括設定後、保存・読込・印刷・PISAに一貫して反映される。

## 7. 日付・保存・読込

- [ ] 新規日付に入力して保存できる。
- [ ] 保存後、同じ日付を読み込むと入力内容が復元される。
- [ ] 別日付を選んだ時、前の日付のデータが混ざらない。
- [ ] 保存済み日付がカレンダーで識別できる。
- [ ] 削除操作で対象日だけ削除される。
- [ ] 最新履歴の読込が正しい日付を選ぶ。
- [ ] 保存失敗時にユーザーへ分かる形で通知される。

## 8. 診療時間・担当者

- [ ] 開始時刻を変更すると終了時刻や所要時間が自然に更新される。
- [ ] 終了時刻を変更すると所要時間が正しく表示される。
- [ ] 現在時刻セットが正しく動く。
- [ ] 5分追加が正しく動く。
- [ ] 日付をまたぐ時刻で表示が破綻しない。
- [ ] 担当者を選択できる。
- [ ] 担当者の色や表示が保存・読込後も維持される。

## 9. PISA表示

- [ ] PPD未入力ではPISAが不自然な値にならない。
- [ ] BOPなしではPISAが0になる。
- [ ] BOPあり、PPDありでPISAが増える。
- [ ] 欠損歯はPISA計算から除外される。
- [ ] 象限別PISAと全顎PISAの合計が一致する。
- [ ] BOP率が総サイト数と陽性数に対して妥当。
- [ ] 第三大臼歯を含む場合も計算が破綻しない。

## 10. 比較モード

- [ ] 比較する日付を選択できる。
- [ ] 複数日付を選んだ時に表示が崩れない。
- [ ] 比較データと現在データが混同されない。
- [ ] 比較中に現在データを編集しても過去データが変わらない。
- [ ] 比較解除後、通常入力へ戻れる。

## 11. 印刷プレビュー

- [ ] 全顎が1画面で確認できる。
- [ ] 1点法、4点法、6点法それぞれで印刷表示が自然。
- [ ] 欠損歯、乳歯、BOP、排膿、プラーク、動揺度が反映される。
- [ ] 拡大縮小しても文字や罫線が読める。
- [ ] A4印刷想定で重要情報が欠けない。

## 12. 性能・操作性

- [ ] 連続入力で体感遅延が少ない。
- [ ] クアドラント移動が速い。
- [ ] 保存・読込で数秒以上待たされない。
- [ ] タッチ対象が小さすぎない。
- [ ] 誤タップした時に復旧しやすい。
- [ ] 検査者が視線を大きく動かさず次の入力へ進める。
